# Contributing

lanternkb is licensed under Apache-2.0. By submitting a contribution you license it under the same terms
(Apache-2.0, section 5).

- Open an issue before a large change, so we can agree on the approach first.
- Report security problems privately, as [SECURITY.md](SECURITY.md) describes, never in a public issue.
- Plugins need no contribution: see [docs/plugins.md](docs/plugins.md).
- Never put real documents, paths or credentials in an issue or pull request. Use synthetic files, and label
  any fake secret as fake.
