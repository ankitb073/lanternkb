# Code of conduct

lanternkb is a small project about privacy, so the first rule follows from that.

- **Respect people's privacy.** Never post someone's files, paths, credentials or personal details, theirs or yours, in issues, discussions or pull requests. Reproduce problems with synthetic data.
- **Be kind and specific.** Criticise code and claims, not people. Say what you measured and how.
- **No harassment** of any kind, in any project space or in private messages about the project.
- **Assume good faith,** and ask before concluding otherwise.

The maintainer may edit or remove anything that breaks these rules, and may block people who keep breaking them. To report a problem privately, use the contact in [SECURITY.md](SECURITY.md).
