# lanternkb-ui

The optional settings page for [lanternkb](https://github.com/ankitb073/lanternkb): folders and tiers, features,
search in the browser, and sync progress. It runs only while you use it (`lanternkb ui`), listens on loopback only,
and exits when closed. It uses the Python standard library and nothing else.

Install it with lanternkb: `uv tool install "lanternkb[embed,ui]"`. Licence: Apache-2.0.
